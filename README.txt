COLETOR DM + EVS — VERSÃO WEB PARA TESTES

Publicação gratuita pelo GitHub Pages:
1. Crie repositório público específico para o aplicativo, sem dados de inspeção.
2. Envie index.html, app.js, sw.js, manifest.webmanifest e icon.svg na raiz.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Abra o endereço HTTPS informado pelo GitHub Pages no Chrome Android.
5. Menu do Chrome > Adicionar à tela inicial.

AVISOS:
- Não coloque informações reais de inspeção no repositório público.
- Dados das baixas ficam somente no armazenamento local do navegador.
- Faça exportações CSV frequentes; limpar dados do navegador pode apagar os registros.
- O OCR usa Tesseract.js via CDN e pode exigir internet; os demais recursos principais ficam disponíveis após cache.
- O reconhecimento precisa ser conferido manualmente; 0/O e 1/I são confundidos.
- Não é um APK e não atualiza planilhas oficiais.
- Este protótipo não foi testado em aparelho real.
